Study · Anki on the reader

Your deck, on the device.

The Study app schedules with the same FSRS algorithm Anki uses and syncs every review back, so the reader is a real Anki client, not an export. This page puts a deck on it: drop the .apkg Anki exports, see your own cards running on the real firmware, then write the deck to the SD card.

Everything on this page happens inside this tab. Your deck is opened, converted and previewed by code running locally; nothing is uploaded anywhere, and the page works offline once loaded.

Drop your deck

step 1 · the .apkg Anki exports

In Anki: File › Export, format Anki Deck Package (.apkg), with Include scheduling information checked so cards arrive as learned as they are, and Support older Anki versions unchecked. A deck downloaded from AnkiWeb's shared decks works too: import it into Anki first, then export it the same way.

The honest report

step 2 · what converts, what cannot

The converter says what it understood, and the checker walks every card asking the questions a glance cannot: can every character be drawn, does every headword fit the screen, does every sentence wrap sanely. What you read below is those tools' own words, not a summary of them. A deck that passes here renders on the device; a card that would surprise you is listed before it can.

The type
step 3 · faces built for this deck





  

    

      A Chinese deck gets the five faces its Anki template randomises between,
      built from the TTFs the package carried, subset to the characters the
      deck really uses. An English deck needs nothing: the reader's built-in
      serif draws it. What a big headword face adds is looks, so one is
      offered, fitted so the deck's longest word spans the screen edge to
      edge.

Write it to the card
step 5 · the SD card, or a zip





  

    

      Put the reader's SD card in this computer, then let the page write the
      deck into its /study/ folder. Decks already on the card are
      left alone; this deck is added alongside them. If your browser cannot
      write folders (Firefox and Safari cannot yet), you get the same files as
      a zip and one sentence about where to unpack it.

After you study: sync back
the loop · reviews return to Anki





  

    

      Reviews you do on the reader are written to the card after every answer.
      To carry them back into Anki, the computer-side tool replays them into
      your collection with the same grades and timestamps, then Anki's own
      Sync button takes them to AnkiWeb. That part lives in the repository
      (tools_local/study/study.py sync) and is documented in
      docs/study.md.
