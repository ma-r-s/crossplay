# Picross pictures -- ORIGINAL artwork, authored for this fork (public domain).
#
# '#' is a solid cell (filled in the finished picture), '.' is empty. The line
# before a grid is its NAME. Blank lines separate puzzles; '#'-prefixed lines
# that are not part of a grid are comments (a grid line is only '#' and '.').

# The generator DERIVES the clues from the picture and refuses any puzzle that
# is not both UNIQUE and LINE-SOLVABLE. Expect designs to be rejected; that is
# the tool working. See docs/apps/picross.md and tools_local/picross/gen_picross.py.
